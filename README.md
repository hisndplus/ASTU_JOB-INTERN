# Job & Internship Finder Platform
A React Native mobile application built with Expo and powered by Onspace AI APK that connects students with employers for jobs and internships. This application includes seeker and employer experiences for browsing, posting, and managing opportunities.

## Features
User Authentication
Job & Internship Listings
Search and Filtering
Resume (CV) Upload
Job Application Tracking
Employer Job Posting Dashboard
Applicant Management
In-app Notifications and Messaging
Tech Stack
React Native
Expo
TypeScript
Onspace AI APK
Firebase/Supabase
React Navigation / Expo Router
Purpose
This platform helps students easily discover and apply for opportunities while helping employers find suitable candidates efficiently.

# Getting Started
Install dependencies:
npm install
# or
yarn install
Start the project:
npm run start        # Start Expo development server
npm run android      # Launch Android emulator
npm run ios          # Launch iOS simulator
npm run web          # Start the web version
Lint the code:
npm run lint
For full setup, dependency details, and project structure, refer to the repository README and documentation files.
