# ASTU_JOB-INTERN

## Introduction

ASTU_JOB-INTERN is a web-based application designed to facilitate job and internship opportunities for students and employers. The platform allows users to register, post jobs or internships, and apply for positions. It provides features for admin, employer, and student roles, supporting a streamlined recruitment and application process. The codebase combines backend and frontend components, following a modular approach for maintainability.

## Usage

ASTU_JOB-INTERN supports three main user types: administrators, employers, and students. Each role has a dedicated dashboard and tailored functionality. Administrators manage system content, employers post and manage job listings, and students search and apply for positions. The application supports user authentication, job posting management, application tracking, and document uploads.

- Students can search and apply for jobs or internships, update their profiles, and upload documents.
- Employers can post new jobs, view applicants, and update job postings.
- Administrators can oversee all users, manage posts, and monitor platform activity.



---

ASTU_JOB-INTERN combines robust backend logic with a user-friendly interface to provide an efficient platform for job and internship management tailored to academic institutions and businesses.

## Job and Internship Finder Platform

Job and Internship Finder Platform is a React Native mobile application built with Expo and Onspace AI APK. It connects students and employers for job and internship opportunities. The application includes seeker and employer experiences for browsing, posting, and managing opportunities.

### Features

- User authentication flows for seekers and employers.
- Job and internship listings with structured opportunity details.
- Search and filtering for relevant opportunities.
- Resume or CV upload for applicants.
- Job application tracking for seekers.
- Employer job posting dashboard for managing listings.
- Applicant management tools for employers.
- In-app notifications and messaging features.

### Tech Stack

- React Native
- Expo
- TypeScript
- Onspace AI APK
- Firebase or Supabase
- React Navigation or Expo Router

### Purpose

This platform helps students discover and apply for opportunities using a mobile experience. It also helps employers find suitable candidates efficiently through integrated tools.

### Getting Started

Install dependencies using npm or yarn.

```bash
npm install
# or
yarn install
```

Start the project with the Expo development server and platform targets.

```bash
npm run start   # Start Expo development server
npm run android # Launch Android emulator
npm run ios     # Launch iOS simulator
npm run web     # Start the web version
```

Lint the codebase to maintain consistency.

```bash
npm run lint
```

For full setup, dependency details, and project structure, refer to the repository README and documentation files.
